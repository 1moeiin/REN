{% comment %} Reveal-image mask — a port of the 21st.dev React component to this stack. The original used framer-motion's useScroll/useSpring/useTransform to drive a clip-path. Same idea here with GSAP ScrollTrigger, which the project already loads: the mask blooms from a small shape to the full frame as the section crosses the viewport. The wordmark sits OUTSIDE the clipped frame so the mask doesn't cut it — it fades in on its own scroll range, layered over the opening image. Params: src, alt, title, caption (optional), shape ("circle" | "rounded"), word (wordmark text, defaults to REN). Reduced motion is handled in the JS, which leaves both fully resolved. {% endcomment %}
